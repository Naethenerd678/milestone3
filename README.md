# Book Search SPA - Milestone 3

This is a **Single Page Application (SPA)** built using **jQuery AJAX** and the **Google Books API**.

## Features
- Search for books by keywords
- Display up to 50 results with **pagination (10 per page)**
- Click on a book to view **detailed information** (title, author, description)
- Explore a **featured collection** of books
- All functionality happens on a single page (SPA behavior)

## Technologies Used
- HTML / CSS
- JavaScript (jQuery)
- Google Books API
